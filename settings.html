Pasang MiniPlayer sebagai aplikasi di perangkatmu

Jika tombol pasang tidak muncul, coba langkah berikut:

  1. Pastikan membuka lewat HTTPS atau localhost.
  2. Pastikan Service Worker terdaftar (Kembali ke Beranda lalu tunggu pesan 'ServiceWorker registered' di console).
  3. Di browser desktop (Chrome) buka menu (⋮) → Install atau Install app.
  4. Jika sudah pernah di-uninstall, muat ulang halaman dan tunggu koneksi, lalu gunakan tombol "Periksa Kesiapan" di atas.
